# Factory 切号器 · 使用说明

一个原生 Mac 菜单栏工具：保存你自己的 Factory 登录，通过官方 Droid
添加账号，查看额度，再手动选择账号切换。不需要 Go 或第三方运行时。

**这是非官方、本机运行的测试版工具，不会自动切号、创建账号、修改服务端额度、
组织权限或 Factory 安装包。请按服务条款和所属组织规定使用。**

## 打开与首次使用

1. 打开 `FactorySwitcher.app`（从 GitHub Release 下载，或按下方“开发与打包”自行构建，
   输出在 `dist/`）。屏幕右上角会出现 **FS**。
   它没有 Dock 图标或常驻主窗口。
2. 选择 **保存 / 同步当前账号**。工具会备份当前的加密登录到自己的目录，
   不会退出 Factory，也不会改变当前登录。
3. 点击 **添加账号（官方登录）**，填一个备注。工具会打开登录终端，
   运行你安装的 Factory.app 自带 Droid，浏览器授权仍由官方完成。
4. 登录成功后，退出这个新终端中的 Droid。通常可按 Ctrl+C；
   不要输入 `/logout`，否则新登录会被清除。
   登录程序退出后，工具会尝试自动保存。也可点 **保存新登录**。
5. 在菜单中点击一个已保存账号，确认后切换。工具会正常退出 Factory，
   保存退出后的最新登录，建立备份，替换登录并重新打开 Factory。

首次访问可能出现 macOS 钥匙串授权提示。只允许你确认可信的切号器，
并保持登录钥匙串已解锁。工具遵守系统授权，不绕过密码提示或修改钥匙串权限。

建议把 App 放在固定位置，例如你自己的 `~/Applications`。
当前构建使用 ad-hoc 签名，未经 Apple 公证；升级或重新编译后，钥匙串可能再次请求授权。
从 Release 下载后首次打开会被 macOS 拦截：请到 **系统设置 → 隐私与安全性**，
在页面底部点击 **仍要打开**。不放心可以从源码自行构建。
不要通过关闭 Gatekeeper 或移除安全保护来运行。

### 登录时出现旧账号

这是浏览器的现有登录状态，不代表工具已经切换。
将 Droid 提供的授权链接复制到浏览器无痕窗口，再登录你想添加的账号。
新增账号始终位于独立 Factory home；添加完成不会替换正在使用的登录。

只能同时添加一个账号。**重新打开登录终端** 前，请关闭旧登录终端中的
Droid 和其他终端 Droid。重复打开的脚本会使用目录锁拒绝并发。
如果终端被强制结束，残留 `run.lock` 可能需要在确认登录进程已停止后
手动移到废纸篓。失败记录保留，可重新打开或取消添加。

## 切号前务必注意

- **切号会退出并重新打开 Factory，正在运行的任务会中断。**
  请先结束任务、保存工作，不要用它中断需要继续运行的代理。
- 终端里的其他 Droid 必须先退出。工具不会强制杀进程。
- 默认每次切号都需要确认，可在 **设置** 中改变。
- 已保存登录仍可能被官方到期、撤销或要求重新验证。保存不等于永久有效。
- 如果账号切换成功但自动打开失败，菜单会说明结果。手动打开 Factory 即可。
- 切号后请确认 Factory 显示的邮箱/组织正确，再开始新任务。
- 不要与其他账号切换器同时运行，也不要在切换进行时手动打开 Factory。
  工具会反复检查进程，但不能阻止其他应用恰好在文件替换期间启动。

## 额度显示

- 显示官方 billing limits 响应中的 5 小时、周、月窗口剩余百分比。
  **额度详情** 可查看套餐组、重置时间和额外余额（接口提供时）。
- 默认每 5 分钟查询一次；可手动刷新，也可在设置中关闭。
- 已结束的窗口显示 **待开启（上次已用…）**，不是当前额度耗尽。
  缺少字段显示未知，不推算或伪造额度。
- 查询失败时保留内存中的上次结果，并标注错误和查询时间；
  重启工具后需要重新查询。
- 对闲置账号，工具可能按官方 refresh-token 流程续期。
  续期结果会先保存，再查询额度。不会输出令牌、密钥或接口响应正文。
- **不会替正在使用的登录续期**，避免与 Factory 的令牌更新冲突。
  检测到终端 Droid，或运行中的同一用户不同组织登录时，也会推迟续期。
  遇到这类提示，可打开对应 Factory 登录，让官方客户端完成续期。
- 额度查询不是模型对话，不发送对话内容；仍受官方接口的访问频率限制。

## 共享所选本地会话

在 **选择要共享的会话** 中勾选，再保持 **共享所选会话（先备份）** 启用。
没有选择时不会修改任何会话。

工具只备份并移除所选 JSONL 会话首行的 `organizationId`，
保留其他头部字段及消息正文（首行会按键名重新排序写回），并让 Droid 重建本地会话索引。
不会批量改变所有会话，不会改写远程记录或授予服务端组织权限。

**继续这些对话时，历史内容可能被发送到目标账号所属的组织。**
请只选择你有权跨账号使用的内容。不要把公司的机密内容带到个人账号，
或混用不同组织的工作对话。

跨账号继续的实际效果还需要你在当前 Factory 版本中手动验证；
本地元数据兼容不等于保证所有云端会话、工具状态或项目权限都能迁移。

## 备份与恢复

切换前必须建立并验证备份。登录或会话修改失败时，工具会尝试恢复原登录
和会话组织标记。准备阶段失败会尝试重新打开原 Factory。

若程序中断，菜单会暂停新操作并显示 **恢复中断的操作**。
未提交操作的恢复需要先关闭 Factory 及所有 Droid。
如果上次切换已经提交，恢复只清理记录，不会改回旧账号。

**备份与恢复 → 恢复…的会话标记** 只恢复所选会话原来的组织标记，
保留之后新增的消息，不替换当前登录。请先退出 Factory/Droid。
如果某条会话已经被绑定到另一组织，工具会拒绝覆盖。

**备份与恢复 → 打开备份目录** 可检查历史备份。
不要编辑备份或复制旧登录文件到正在运行的 Factory 中。
旧 refresh token 可能失效，历史备份并不是永久可用的登录。

## 本机数据与隐私

| 内容 | 位置/方式 |
| --- | --- |
| 账号备注、邮箱、用户/组织标识、偏好 | `~/.factory-switcher/state.json` |
| 加密登录快照 | `~/.factory-switcher/accounts/` |
| 登录备份、所选会话副本及恢复记录 | `~/.factory-switcher/backups/` |
| 官方登录的独立 home 与终端脚本 | `~/.factory-switcher/logins/` |
| 快照及备份的加密密钥 | 本机钥匙串，服务 `local.FactorySwitcher.keys` |
| Factory 当前登录使用的密钥 | 官方服务 `Factory CLI`，按需读写 |

新建敏感目录为 0700，敏感文件为 0600；切换时也会把 `~/.factory` 目录本身设为 0700。快照文件没有明文密钥。
官方 Droid 的文件式 fallback 登录可能在独立 home 中创建
`auth.v2.key`，工具会用私有目录权限保护它。
登录备份中的这类密钥转存到钥匙串，不与备份密文放在一起。

**会话备份包含完整对话正文，未另行加密。** 账号备注、邮箱、标识也不是加密数据。
它们由本机私有文件权限保护；其他能以你的用户身份运行的软件仍可能访问。
建议启用 FileVault，不要上传整个数据目录或把它放进云同步共享目录。
磁盘数据并不防御已经取得你登录用户权限的恶意软件。

为了恢复，历史加密快照、密钥和登录目录不会自动清理。
**从菜单移除账号** 只移除菜单记录，不撤销官方登录、不删除历史密钥；
后台同步不会自动把刚移除的账号加回来。但如果被移除的账号仍是 Factory 当前登录，
之后点击 **保存 / 同步当前账号** 或切换账号时，它会作为当前登录重新加入菜单。
若要完整卸载，先退出切号器和登录终端，将 `~/.factory-switcher`
移到废纸篓，再通过“钥匙串访问”删除服务为
`local.FactorySwitcher.keys` 的项目。此操作会失去工具的全部备份恢复能力。
**不要删除 `Factory CLI` 的当前密钥、`~/.factory` 或你的 Factory 会话。**

联网仅用于用户发起的官方登录、官方额度查询和适用的官方登录续期，
不接入额外分析/遥测服务，不上传本地备份。

## 开发与打包

环境：macOS 13+，Swift 6+ / Xcode 或 Command Line Tools。
当前交付为本机 Apple Silicon 构建，未验证 Intel Mac 或旧版 macOS。

```bash
swift test
swift build -c release
bash scripts/build-app.sh
```

输出：`dist/FactorySwitcher.app`。构建脚本最后的界面自检会创建菜单栏项目，
需要在有图形界面的登录会话中运行。重新打包会保留上一构建到
`dist/previous-builds/`，不会删除旧构建或接触真实 Factory 数据。
构建脚本会检查 plist、签名，并运行不访问真实账号的界面及登录脚本自检。
脚本自检只在临时目录运行 `/usr/bin/true` 作为替身，不运行真实 Droid。

```bash
dist/FactorySwitcher.app/Contents/MacOS/FactorySwitcher --smoke-test
```

实现分为 `SwitcherCore`（文件、钥匙串抽象、配额、备份、事务）及
`FactorySwitcher`（AppKit 菜单、官方登录终端、正常退出/启动）。

## 验证范围

自动测试使用模拟 JWT、内存钥匙串、假的进程/网络和临时目录。
覆盖加密互操作、文件权限/锁/符号链接、未知字段保留、退出失败、
写入失败回滚、崩溃恢复、提交后恢复、选择性共享、保留新增消息、
令牌旋转与额度错误。界面自检覆盖实际菜单和会话选择控件的状态。

**开发期间没有退出真实 Factory、切换真实账号、续期真实令牌或改动
真实会话。** 钥匙串授权、官方浏览器登录、真实额度以及切号后会话继续
需要手动验收。

兼容性依据：研究时安装的 Factory.app 0.187.0 / Droid 0.230.0，
Mac `auth.v2.loginkeychain` 和 `auth.v2.file` 格式。
将来官方存储/API/会话格式改变时可能需要更新工具，遇到不认识的格式
会停止操作，不会猜测处理。
