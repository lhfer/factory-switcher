# FDE Sandbox Gatekeeper

Two-tier content & code security inspection pipeline for a ~1,000-member Forward Deployed Engineer (FDE) community sharing MCP servers, connectors, and deployment scripts.

## Architecture

```mermaid
flowchart LR
    A[Community Post Event] --> B[Webhook Ingress]
    B --> C{Tier 1 Sync Filter<br/>Regex + Gitleaks + AST<br/>< 200ms}
    C -->|Plain Text / Safe ~85%| D[Auto Approve]
    C -->|Executable Code / Repo / High Entropy ~15%| E[SHA-256 Dedup Check]
    E -->|Cache Hit| F[Reuse Verdict]
    E -->|Cache Miss| G[Mark Post: Sandbox Verifying]
    G --> H[Async Queue]
    H --> I[Devin API Sandbox Analysis]
    I --> J[Callback Webhook + HMAC Verify]
    J -->|Clean| K[Mark Verified]
    J -->|Risk / Timeout| L[Quarantine + Line-level Fix]
